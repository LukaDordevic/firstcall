# Beachhead

Live app: https://firstcall-3dtg.onrender.com  
Repo: https://github.com/LukaDordevic/firstcall

GTM intelligence for a newly-built B2B startup with no sales team yet.

1. Paste the startup URL — watch the GTM brain fill in live (Convex).
2. **Strategy** — target industries and partner categories, each with reasoning and a motion.
3. **Find leads** — Exa searches the live web for real companies.
4. **Prepare** a lead — Firecrawl + news signals + a recommended approach.
5. **Roleplay** the conversation (browser mic + speech).

## Stack

Convex, Firecrawl, Exa, x.ai (Grok 4.6), Vite/React/Tailwind, Render.

API keys live on the Convex deployment only. Never in the browser.
